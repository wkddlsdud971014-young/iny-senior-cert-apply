# Part A. 기능테스트

기능 하나씩 따로 꺼내서 작동하는지 확인합니다.

## 필수 - Must (전부 통과해야 완료)

- [ ] **M1.** 배포 주소가 열린다 - Vercel 주소를 **시크릿 창 또는 폰**에서 열었을 때 접수 화면이 뜬다
- [ ] **M2.** 자격증을 고를 수 있다 - 자격증 1개를 선택하면 화면에 선택 표시가 뜬다. 선택한 자격증: ____________
- [ ] **M3.** 접수 폼 제출 - 이름, 연락처 입력 후 접수 버튼을 누르면 에러 없이 제출된다
- [ ] **M4.** DB에 저장됨 - Supabase Table Editor에서 방금 제출한 행이 보인다. 이름/자격증/연락처 일치
- [ ] **M5.** 새로고침 후 잔존 - Supabase 대시보드 F5 후에도 행이 그대로 있다
- [ ] **M6.** 어드민에서 조회 - admin 페이지를 열면 방금 접수한 내역이 표에 나온다
- [ ] **M7.** 다른 자격증 재접수 - 다른 자격증으로 새 이름을 넣어 한 번 더 접수. DB에 행이 하나 더 생긴다
- [ ] **M8.** 어드민에 2건 표시 - 어드민 새로고침 후 2건 모두 표에 보인다

## 필수 - Should (전부 통과하기)

- [ ] **S1.** 이름 빈칸 차단 - 이름을 비우고 접수 버튼 -> 제출이 안 되거나 안내가 뜬다
- [ ] **S2.** 자격증 미선택 차단 - 자격증을 안 고르고 접수 버튼 -> 안내가 뜬다
- [ ] **S3.** 연락처에 글자 차단 - 연락처에 "abcd" 입력 후 제출 -> 차단 또는 형식 안내
- [ ] **S4.** 연락처 자릿수 부족 - 연락처에 "010"만 넣고 제출 -> 차단 또는 안내
- [ ] **S5.** 어드민 비밀번호 보호 - 시크릿 창에서 어드민 주소 -> 비밀번호 없이는 내역이 안 보인다. 비밀번호 없으면 "없음" 기록
- [ ] **S6.** 틀린 비밀번호 차단 - 어드민 비밀번호에 "xxxx" 입력 -> 접근 거부
- [ ] **S7.** 접수 후 어드민 실시간 반영 - 폼에서 1건 제출 후 어드민 새로고침 -> 방금 건이 추가됨
- [ ] **S8.** 같은 사람 2번 접수 - 같은 이름, 같은 자격증으로 2번 -> DB에 2행 생김

## 선택 - Could (하면 가산점)

- [ ] **C1.** 폰에서 읽힘 - 폰 브라우저에서 가로 스크롤 없이 보이고 버튼 작동
- [ ] **C2.** 100건 표시 - CSV import 후 어드민에 100건이 보인다
- [ ] **C3.** 폼 초기화 - 접수 성공 후 입력값이 지워져 있다
- [ ] **C4.** 자격증별 구분 - 어드민에서 정렬 또는 필터 가능

## 우선순위 낮음 - Won't

- FAQ 챗봇 동작
- FAQ 어드민 문서 수정
- 챗봇 threshold 조정
- 비슷한말 사전
- 통합 테스트 (폼 -> 챗봇 -> 어드민 한 바퀴)
- 사용성 평가 (옆 사람 서비스 5분 체험)

# Part B. 시나리오 테스트

실제 사용자가 처음부터 끝까지 쓰는 흐름을 따라가면서, **어디서 막히는지**를 찾습니다.

## 필수 - 시니어 시나리오 (5개 중 3개 이상)

시나리오 속 인물이 되어 처음부터 끝까지 써봅니다. **"막힌 곳"을 반드시 적습니다.**

### US1. 요양보호사 접수하는 62세

> 김순자(62세)가 학원 직원에게 받은 링크로 요양보호사 시험을 접수합니다.

- [ ] 링크를 눌러 접수 화면을 연다 - 뭘 해야 하는지 알겠다
- [ ] 8종 중에서 요양보호사를 찾는다
- [ ] 요양보호사를 선택한다 - 내가 고른 게 맞는지 표시된다
- [ ] 이름 "김순자" 입력 - 글씨가 잘 보이고 입력칸을 찾겠다
- [ ] 연락처 "01087654321" 입력
- [ ] 접수 버튼 - 접수가 됐다는 걸 알 수 있다
- [ ] 접수 완료 안내가 화면에 남아있다

막힌 곳: ____________  
글씨 크기 (팔 뻗은 거리에서 읽힘): O / X

### US2. 지게차 면허 갱신하는 68세

> 박영수(68세)의 지게차 필기 재응시를 학원 직원이 대신 접수합니다.

- [ ] 접수 화면에서 지게차운전기능사를 찾는다
- [ ] 선택한다 - 선택 표시가 뜬다
- [ ] 이름 "박영수" 입력
- [ ] 연락처 "01055551234" 입력
- [ ] 접수 버튼 - 완료 표시
- [ ] 어드민에서 "박영수 / 지게차운전기능사" 확인

- [ ] 오늘 접수 건을 셀 수 있다 (행 수 또는 건수 표시)

# DB 통합 결과 리포트

> `data/real_1000/` 의 CSV 3개를 `통합_접수_1000.csv` 하나로 합친 결과입니다.
> 실행: `python3 merge.py real_1000`

## 1. 합친 결과

| 출처 | 행 수 |
|---|---|
| 두두넷 국가기술자격 | 500 |
| 두두넷 전문자격 | 200 |
| 두두보건 | 300 |
| **합계** | **1,000행 / 46칸** |

판정 못 한 값 **0건**, 사람이 확인해야 하는 행 **0행**.

## 2. 검증 7가지 — 전부 통과

| # | 확인한 것 | 결과 |
|---|---|---|
| 1 | 행 수가 500+200+300 인가 | ✅ 1,000행 |
| 2 | 접수번호가 겹치지 않는가 | ✅ 중복 0건 |
| 3 | **원본 칸이 원본 파일과 한 글자도 다르지 않은가** | ✅ 다른 곳 0군데 |
| 4 | 표준 칸이 정해진 값만 쓰는가 | ✅ 6개 칸 전부 |
| 5 | 날짜 형식이 어긋난 것이 없는가 | ✅ 0건 |
| 6 | 빈 칸이 전부 설명되는가 | ✅ 4개 칸 전부 |
| 7 | 금액 합계가 원본과 같은가 | ✅ 20,339,400원 일치 |

**3번이 가장 중요합니다.** 원본을 고치지 않았다는 것을 5개 칸 × 1,000행으로 대조해 확인했습니다.

## 3. 표기를 맞춘 결과

| 칸 | 통합 후 |
|---|---|
| 성별 | 남 517 / 여 483 |
| 결제수단 | 신용카드 409 / 계좌이체 338 / 가상계좌 253 |
| 결제상태 | 완료 877 / 환불 75 / 대기 48 |
| 접수상태 | 접수완료 877 / 취소 75 / 결제대기 48 |
| 감면유형 | 없음 802 / 장애인 88 / **기초생활수급자 68** / 국가유공자 26 / 차상위계층 16 |

합치기 전에는 `기초생활수급자`·`BASIC_LIVING`·`기초수급` 세 줄로 쪼개져 있던 것이 **68명 한 줄**이 됐습니다.

## 4. 빈 칸 — 전부 설명됩니다

빈 칸은 실수가 아니라 **원래 없는 정보**입니다.

| 칸 | 빈 칸 | 이유 |
|---|---|---|
| 시험지역 | 300행 | 두두보건에는 지역 칸 자체가 없음. `청주센터`에서 `청주`를 뽑으면 다른 DB의 `충북`(광역)과 기준이 어긋나 **비워 둠** |
| 회차 | 906행 | 상시CBT 406 + 전문 200 + 두두보건 300. 정기시험에만 있는 정보 |
| 차수 | 800행 | 1차·2차는 전문자격 200행에만 있음 |
| 교육기관 | 700행 | 교육수료는 두두보건 300행에만 있음 |

`0`이나 `없음`으로 채우지 않았습니다. **없는 것과 0은 다르기 때문**입니다.

## 5. 표준화하지 않은 것

**교시 / 시간대** — 국가기술은 `1~5교시`, 두두보건은 `AM/PM` 으로 서로 다른 개념입니다.
정책 문서에도 상시CBT(406건)는 교시 번호와 시각이 연결돼 있지 않아, 맞추려면 추측이 들어갑니다.
`교시_원본`에 원본만 남겼습니다.

# 자격증 8종 안내 규정 (사내 원장 v1)

> 두두자격지원센터 접수팀 / 2026-08-19 정리
> 직원이 전화로 안내할 때 보는 문서입니다. 여기 없는 것은 저희도 모릅니다.
> **필기 접수까지만 다룹니다.** 실기는 저희 소관이 아니라 이 문서에 넣지 않았습니다.

## 0. 이 문서를 정리하면서 알게 된 것

8종을 한 창구에서 안내하는 줄 알았는데 **접수 방식이 세 갈래로 갈립니다.**

| 방식 | 자격증 | 접수 기간 |
|---|---|---|
| **정기 회차** | 전기기능사 | 연 4회, 정해진 기간에만 |
| **상시** | 한식조리기능사, 지게차운전기능사, 굴착기운전기능사, 요양보호사 | **기간 없음** |
| **1차·2차** | 손해평가사, 공인중개사 | 연 1회 |

**"언제 접수해요?"라는 같은 질문에 답이 세 가지입니다.** 정기는 날짜를 알려드리고, 상시는 "아무 때나 되는데 자리가 있어야 한다"이고, 1차·2차는 "올해는 끝났다"일 수 있습니다.

## 4. 결제와 환불

### 결제 마감

- 원서접수 마감일 **18시**까지
- 단, 정기 필기는 마감일 18시 전까지 원서 작성을 마치고 시험장 자리가 있으면 **24시까지** 결제 가능 (계좌이체·신용카드만)

### 가상계좌 입금 기한

| 접수 시점 | 입금 기한 |
|---|---|
| 마감일 전날 12:59:59까지 접수 | 접수 당일 14시까지 |
| 마감일 전날 13:00부터 접수 | 다음날 14시까지 |
| 마감일 당일 12:59:59까지 접수 | 접수 당일 14시까지 |
| 마감일 당일 13:00부터 접수 | **사용 불가** |

기한까지 입금하지 않으면 **원서가 자동 취소**됩니다.

### 환불

| 시점 | 환불률 |
|---|---|
| 접수기간 내 취소 | **100%** (마감일 23:59:59까지) |
| 접수기간 후 ~ 시험 5일 전 | **50%** (10원 미만 절사) |
| 시험 4일 전부터 | **환불 불가** |

기준일은 수험자 본인의 시험일이 아니라 **해당 회차 시험 시작일**입니다.

환불금 입금까지 최대 7일 걸리고 입금자명은 "토스페이먼츠"입니다. 별도 통보가 없으니 통장을 확인하시라고 안내합니다.

### 사후 환불 (접수기간 밖)

아래에 해당하면 100% 환불됩니다. 마이페이지에서 서류를 첨부해 신청합니다.

- 본인 또는 배우자의 가족(부모·조부모·형제자매·자녀)이 시험일 7일 전까지 사망
- 본인이 사고·질병으로 입원 (입원기간에 시험일 포함)
- 국가 인정 전염병 확진 또는 격리 (격리기간에 시험일 포함)
- 군인·군무원이 국가 위기단계로 휴가·외출 금지
- 예상 못 한 기후로 거주지에서 시험장까지 대중교통 두절

## 5. 필기 합격의 유효기간

**국가기술자격(기능사)은 필기 합격이 2년간 유효합니다.**

국가기술자격법 제12조, 시행령 제16조. 2014년 1월 1일 개정으로 2년 제한이 생겼습니다.

즉 필기에 한 번 붙으면 **2년 동안은 필기를 다시 안 봅니다.** 2년이 지나면 필기부터 다시 봐야 합니다.

**공인중개사는 다릅니다.** 1차 합격 시 다음 회차 1회에 한해 면제되고, 유효기간은 합격 연도를 포함해 1년입니다. 다만 이건 저희가 공식 문서로 확인하지 못했습니다 - **공식 사이트에서 확인해 주십시오.**

**뭉뚱그려 "2년"이라고 답하면 안 됩니다.** 자격증마다 다릅니다.

## 6. 접수는 어떤 순서로 하나

두두넷 접수 화면은 이 순서로 넘어갑니다.

| 단계 | 화면 | 하는 일 |
|---|---|---|
| 1 | 약관 동의 | 사진 규격, 신분증 범위 등 4가지에 동의 |
| 2 | 기초정보 입력 | 학력·경력 설문에 체크 |
| 3 | 자격 선택 | 정기 / 상시 / 전문자격 중에서 시험을 고름 |
| 4 | 종목 선택 | 종목명을 검색창에 넣어 고름 |
| 5 | 장소 선택 | 지역·시험장·날짜·시간대를 골라 자리를 잡음 |
| 6 | 결제 | 종목과 사진을 최종 확인하고 신용카드 / 계좌이체 / 가상계좌 |
| 7 | 접수 완료 | 수험표 출력 |

접수 기간이 아니면 3단계에서 **"현재 접수중인 시험이 없습니다"**만 뜹니다.

2단계 학력·경력은 접수 기간 전에 **사전입력**으로 미리 넣어 둘 수 있습니다. 그러면 접수 당일에는 장소 선택과 결제만 하면 됩니다.

**자리는 5단계에서 마감됩니다.** 시험장과 시간대는 선착순이라 늦으면 원하는 자리가 없습니다.

### 접수하기 전에 준비할 것

| 항목 | 내용 |
|---|---|
| 회원가입 | 필수 |
| 인증서 | 공동인증서 또는 금융인증서 등록 |
| **사진 등록** | **6개월 이내 촬영, 3.5x4.5cm 컬러, 상반신 정면, 모자 없이, 배경 없음** |

사진이 규격에 안 맞으면 자동인식 프로그램이 접수를 거부합니다. 스냅사진·선글라스·스티커사진·측면사진·모자착용·복잡한 배경은 안 됩니다.

본인 사진이 아니면 시험 당일 각서를 쓰거나 응시가 안 될 수 있습니다.

### 접수 방식

- 온라인(인터넷, 모바일앱)에서만 됩니다. **방문 접수는 없습니다.**
- 지역에 상관없이 원하는 시험장을 고를 수 있습니다.
- 수험 일시와 장소는 접수 즉시 통보됩니다.

## 7. 시험 시간과 준비물

### 필기시험 시간

| 등급 | 시간 |
|---|---|
| **기능사** | **60분** |
| 기능장 | 60분 |
| 기사·산업기사 | 과목당 30분 |
| 서비스 | 150분 |
| 기술사 | 4교시, 교시당 100분 |

과목 면제를 받으면 응시하는 과목만큼만 시간이 주어집니다.

### 시험 당일 지참

수험표, 신분증, 필기구(흑색 사인펜)

시험실에 들고 들어갈 수 있는 것은 이 8가지뿐입니다.
신분증 / 수험표 / 필기구 / 수정테이프 / 시각표시만 되는 시계 / 전자계산기 / 지정 수험자지참공구 / 간식

**휴대폰, 스마트워치, 태블릿, 전자사전, 통신 기능 있는 시계는 반입 금지입니다.** 소지품 정리시간 이후에 갖고 있으면 시험이 무효 처리됩니다.

## 8. 접수 공통 규칙

- 원서접수 시간: 첫날 **10:00** ~ 마지막 날 **18:00** (전문자격 37종목은 09:00 시작)
- **주말·공휴일·공단창립기념일(3월 18일)에는 접수 불가**
- 필기 합격예정자 발표 시간 = 발표일 **09:00**
- 수험표는 접수 당일부터 시험일까지 출력 가능. 그 외 기간은 조회 안 됨
- 브라우저는 Edge, Chrome, Safari 사용
